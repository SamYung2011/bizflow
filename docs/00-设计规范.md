# 任务平台 · 设计规范

> 本文件保留部署仓直接引用的设计 token 规范；视觉实测仍以 Figma 最新稿为准。

## 2. 颜色

### 2.1 全局纯色档

| 变量 | 色值 | 用途 |
|---|---|---|
| `--blue` | `#0468EA` | 主色、小控件、菜单渐变族；既有收编口径不变 |
| `--blue-bright` | `#0099FF` | Add 描边、卡片蓝渐变尾色 |
| `--red` | `#DC2626` | 通用危险、删除、红点徽标 |
| `--red-strong` | `#E01010` | 高优先级、Figma 危险操作精确红 |
| `--yellow` | `#EAB308` | 警示、保修到期 |
| `--green` | `#28BA28` | 成功、完成、低优先级 |
| `--white` / `--black` | `#FFFFFF` / `#000000` | 基础色 |
| `--3a` | `#3A3A3A` | 既有深灰语义档 |
| `--gray-5` | `#F5F7FA` | 带冷色相的页面底色 |
| `--gray-6` | `#F5F5F5` | Figma 浮层、输入中性浅灰 |
| `--gray-8` | `#F0F0F0` | 面板、输入底灰 |
| `--gray-10` | `#E5E7EB` | 带冷色相的分隔、未激活 chip |
| `--gray-11` | `#E5E5E5` | Figma chip、输入中性灰 |
| `--gray-12` | `#D9D9D9` | 控制线、segment 底灰 |
| `--gray-15` | `#C4C4C4` | chip 底、列表分隔线 |
| `--gray-20` | `#9CA3AF` | 既有占位文字档 |
| `--gray-25` | `#979797` | Figma 占位、次级控件精确灰 |
| `--gray-40` | `#6B7280` | 既有次级文字档 |
| `--gray-50` | `#5C5C5C` | Figma 次级文字、深灰按钮精确灰 |
| `--gray-60` | `#374151` | 正文深灰 |
| `--gray-70` | `#2E2F30` | Figma 深色关闭控件精确灰 |
| `--gray-80` | `#1F2937` | 标题近黑 |

灰阶依深浅按数字递增；同明度但冷色相与中性色不同的 Figma 实测值分档保存，不再近似映射。跨两个以上模块复现的精确值必须定义在 `tokens.css`，业务 CSS 只能引用变量，不得重复声明十六进制字面值。单模块孤值保留局部变量与来源注释。

2026-07-21 升格：`#5C5C5C`、`#F5F5F5`、`#E5E5E5`、`#979797`、`#E01010`、`#0099FF`、`#2E2F30`。`--blue: #0468EA` 的菜单渐变/小控件收编口径不变；分段控件与按钮多族并行另列后续统一，不在本次改动。
